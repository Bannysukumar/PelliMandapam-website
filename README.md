## Overview

Pelli Mandapam Website is a Next.js site. Visible sections include Login page, Mandapams/Id/Book page, Mandapams/Id page, Mandapams/Compare page, Mandapams page, (Public) page, Register page, Support page.


What is actually in the repository: `app/`, `components/`, `hooks/`, `lib/`, `styles/`. GitHub reports the primary language as TypeScript.

Published site recorded on the repository: https://pelli-mandapam.vercel.app

## Features


- Login page
- Mandapams/Id/Book page
- Mandapams/Id page
- Mandapams/Compare page
- Mandapams page
- (Public) page
- Register page
- Support page
- Vendor/Register page
- Vendors/Vendor Id page
- Account/Bookings/Id page
- Account/Favorites page

## Getting Started

```bash
git clone https://github.com/Bannysukumar/PelliMandapam-website.git
cd PelliMandapam-website
npm install
npm run dev
```

Scripts defined in package.json:

- `npm run dev` — `next dev --turbo`
- `npm run build` — `next build`
- `npm run start` — `next start`
- `npm run lint` — `next lint`
